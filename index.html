แชร์เว็บแอป & QR Code

ขณะนี้เปิดอยู่ในโหมด Preview ยังไม่มีลิงก์เว็บไซต์สาธารณะ

หน้าต่าง Preview ใช้ที่อยู่จำลองภายในระบบ จึงไม่แสดง QR Code จำลองเพื่อป้องกันกล้อง iPhone แจ้งว่า "No usable data found"

1

สร้าง QR Code สแกนได้จริง: กดปุ่มแชร์ของหน้าต่าง Preview ด้านบน หรืออัปโหลดไฟล์แอปขึ้นเว็บฟรีอย่าง Netlify Drop (app.netlify.com/drop) แล้วนำลิงก์ https://... มาวางในช่องด้านล่าง

2

ส่งไฟล์แอปให้เพื่อนทันที: กดปุ่มดาวน์โหลดไฟล์เว็บแอป .html ด้านล่างเพื่อส่งต่อทาง LINE / AirDrop หรือนำไปโฮสต์ขึ้นเว็บฟรีได้ทันที

พร้อมสแกนด้วยกล้อง iPhone / Android
